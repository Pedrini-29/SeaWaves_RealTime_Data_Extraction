# SeaWaves_RealTime_Data_Extraction

This is a project for personal and educational use only.

The script extract the last available data from live buoys recording wave forcasting data.

The data is then added to geolocated markers on an interactive map.
Clicking on the marker opens a popup with all the most recent informations extracted from this buoy.

- Example1.png and Example2.png are graphical examples of the interactive map.
- buoys.html can be opened in the browser as an example of interactive map.
